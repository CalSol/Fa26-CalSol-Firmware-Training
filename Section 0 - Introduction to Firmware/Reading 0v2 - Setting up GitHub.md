# Setting up GitHub

Github is an online cloud-based platform where people store, share, and work together on computer code. It is also a tool for us to use for
version control.

## Create an account:
Create a github account at [here](https://github.com/) if you haven't already.

**Action Item**: Reach out to the Electrical PMs on Slack with your email so we can add you to the club Github repository. 
Once you have been added to the GitHub repository, the next step is to clone the repository onto your computer.
We recommend using GitHub Desktop to make this process easier. You can download GitHub Desktop [here](https://desktop.github.com/download/)

This lab will use GitHub Desktop for all Git-related tasks. However, if you are comfortable using Git through the command line, you may also use
Git Bash instead.

This is a useful link from CS61B this semester on how to set up Git Bash for your computer. [here](https://fa26.datastructur.es/homeworks/hw01/).
Please refer to task 1 and choose the appropriate OS (Windows, Mac, Linux,...) of your computer for the right setup instructions.

## Additional Info:
### Cloning a repository:
To clone a repository is to download a complete local copy of a project, including all its files, branches, and version history.

Here is a youtube video on how to do that in GitHub Desktop: https://www.youtube.com/watch?v=PoZNIbs_wx8
