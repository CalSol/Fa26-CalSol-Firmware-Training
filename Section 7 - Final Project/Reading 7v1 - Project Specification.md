# Brakelights Project Spec
As previously mentioned, you will be programming an ESP32 Dev Board to control a “brake lights” system. Due to hardware limitations (i.e. not having a whole car) we will be modeling this system with two ESP32s. There will be a pre-programmed “pedals” ESP32 which will send/receive CAN data to/from the “brakelights ESP32, which you will program.
